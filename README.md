# NativeCanvas | Pre-Release

Легкий, быстрый и полностью автономный 2D-векторный редактор.

Никакого браузера под капотом, никакого ожидания загрузки и никаких подписок. NativeCanvas создан как простая и отзывчивая альтернатива тяжелым веб-редакторам: мгновенный отклик, плавная работа холста и хранение файлов только локально на вашем компьютере.

---

### Главное

*  **Мгновенный отклик** — холст летает при зуме и перетаскивании объектов.
*  **100% Офлайн и приватность** — работает без интернета, не требует аккаунтов и не отправляет данные наружу.
*  **Привычный дизайн-процесс** — фреймы, геометрические фигуры, удобные слои и детальная настройка свойств.
*  **Математика в полях ввода** — можно считать прямо в инспекторе (например, написать `420 / 2` или `100 + 16`).
*  **Сетка и привязка** — быстрое выравнивание элементов по шагам для аккуратной верстки.
*  **Минималистичный Bento-интерфейс** — чистая темная тема, плавающие панели и фокус только на работе.

---

### Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| `V` / `H` | Выбор объектов / Перемещение по холсту (Рука) |
| `R` / `O` / `L` / `F` | Создать: Прямоугольник / Эллипс / Линию / Фрейм |
| `G` / `Shift + G` | Включить сетку / Включить привязку к сетке |
| `Ctrl + Z` / `Ctrl + Y` | Отменить / Повторить действие |
| `Delete` / `Backspace` | Удалить выбранное |
| `Ctrl + S` / `Ctrl + O` | Сохранить / Открыть проект |
| `Ctrl + R` (над слоями) | Переименовать слой |
| `Esc` | Снять выделение / Закрыть меню |

###  Запуск

Для сборки и запуска нужен установленный [Rust](https://www.rust-lang.org/):

```bash
# Клонируем репозиторий
git clone [https://github.com/stylizedapp/Native-Canvas.git](https://github.com/stylizedapp/Native-Canvas.git)
cd Native-Canvas

# Запуск приложения
cargo run
